개인정보처리방침

시행일: 2026년 10월 16일

왜이럴랩 자동화는 채널 운영자의 PC에서 과학 Shorts를 제작하고 YouTube 업로드를 예약하는 개인 운영 도구입니다.

접근하는 정보와 목적

Google OAuth로 승인받은 YouTube 업로드 권한(youtube.upload)과 조회 권한(youtube.readonly)을 사용합니다. 연결한 채널의 ID·이름과 업로드 영상의 처리·공개 상태를 조회하여 대상 채널을 확인하고, 완성 영상·제목·설명·공개 예약 시각을 YouTube에 전송합니다. Google 비밀번호는 프로그램이 수집하지 않습니다.

보관과 보호

OAuth 갱신 토큰은 운영자 Windows 계정의 DPAPI로 암호화해 로컬에 보관합니다. 채널 식별 정보, 작업 이력, 출처 정보와 렌더링 파일도 운영자의 PC에 저장합니다. 로그에 토큰을 기록하지 않도록 구성합니다. 로컬 자료는 운영자가 삭제하거나 연결을 해제할 때까지 보관할 수 있습니다.

공유와 이용 제한

Google 사용자 데이터는 승인된 채널 관리와 업로드 기능에만 사용합니다. 판매하거나 광고 타기팅에 사용하지 않으며 범용 AI 모델 학습에 사용하지 않습니다. YouTube API 작업에 필요한 정보는 Google/YouTube로 전송됩니다. 영상 검토에 사용하는 Ollama는 로컬에서 실행합니다. 법령상 요구가 있거나 이용자가 명시적으로 동의한 경우 외에는 별도로 제3자에게 제공하지 않습니다.

Google API에서 받은 정보의 사용과 이전은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

홈페이지

이 안내 사이트에는 로그인·회원가입·분석 추적 기능을 넣지 않았습니다. GitHub Pages가 사이트 제공을 위해 접속 정보 등을 처리할 수 있으며, 해당 처리에는 GitHub 개인정보처리방침이 적용됩니다.

철회와 삭제

Google 계정의 서드 파티 연결 관리에서 접근 권한을 철회할 수 있습니다. 로컬 프로그램의 06_PAUSE.cmd로 자동 작업을 중지하고 로컬 토큰과 작업 자료를 삭제할 수 있습니다. 이미 YouTube에 업로드된 영상은 별도로 YouTube Studio에서 관리해야 합니다. 삭제 지원 및 개인정보 관련 문의: k01054049116@gmail.com.
